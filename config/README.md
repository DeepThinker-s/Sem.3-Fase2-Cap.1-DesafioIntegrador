# Configuração

O projeto não exige chaves, contas externas ou variáveis de ambiente. Os caminhos
de entrada e saída possuem valores padrão relativos à raiz e podem ser alterados
pelos argumentos de `src/extrair_diagnosticos.py`.

Ambiente validado: Python 3.12.14 no Windows. O código também é verificado pelo
GitHub Actions em Python 3.12.
